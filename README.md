# Expense Split System

## Overview

Expense Split System is a full-stack web application designed to simplify shared expense management among friends, families, roommates, and teams. The application allows users to create groups, add expenses, automatically split bills, track balances, and manage settlements through a secure and user-friendly interface.

## Features

- User Registration and Login (JWT Authentication)
- Create and Manage Expense Groups
- Add, Edit, and Delete Expenses
- Automatic Expense Splitting
- Real-Time Balance Tracking
- Settlement Management
- Secure Authentication and Authorization
- Responsive User Interface
- RESTful API Integration

## Project Workflow

1. User Registration/Login
2. Create or Join Groups
3. Add Shared Expenses
4. Automatically Calculate Individual Shares
5. Track Outstanding Balances
6. Settle Payments
7. View Expense History
